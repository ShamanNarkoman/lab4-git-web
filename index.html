TrafficFlow CRM/Analytics Hub

Інформаційна система для digital-агенції з медіабаїнгу та інфлюенс-маркетингу.

Про проєкт

Система централізує облік виробництва відеокреативів (TikTok, Reels, Shorts), автоматизує трекінг трафіку через Postback API та розраховує окупність кампаній (ROI/ROAS).

Користувачі

  • Медіабаєр / Тімлід
  • Контент-креатор
  • Фінансовий менеджер

Модулі системи

  1. Dashboard — ключові KPI: Spend, Revenue, ROI, Conversions
  2. Creatives & Tasks — канбан-дошка виробництва відео
  3. Tracking Links — облік партнерських посилань
  4. Finance & P&L — виплати креаторам і фінансовий результат
